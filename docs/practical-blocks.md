# Composition and practical blocks

The standard pack now includes 33 definitions and 47 rootable examples/templates/patterns. Reusable patterns cover features, services, contact strips, price lists, comparison, link-in-bio, filtered services and portfolio galleries. Patterns remain ordinary editable nodes.

New blocks: heading, buttons, icon, icon list, social links, divider, anchor, tabs/tab panel, accordion/accordion item, table, table of contents, breadcrumbs, video, location and enquiry form. Panels accept 1–8 child panels. Core can render without Components; the public pack and forms can run without Filament. The optional editor exposes the same property schema and child rules.

Heading IDs derive from occurrence addresses, so repeated global sections receive separate stable IDs; copying a node gives it a new address. A contents block uses resolved visible body H2/H3 headings (optional H4), including headings after it. Fragment navigation opens containing tabs and disclosures. Explicit anchor names must be unique across visible body/header/footer when publishing. Breadcrumbs use published ancestors and the current page; bind the core BreadcrumbProvider contract for host navigation rules.

Tabs support arrows, Home/End and RTL; without JavaScript their sections remain readable. Accordion uses native details/summary. Tables have a caption, column headings and a horizontally scrollable wrapper. Curated SVG icons come from bundled Heroicons and Simple Icons; provide a label for meaningful standalone icons. No remote icon/font service is required.

Enable collection text search and/or tag filtering separately on each cards/gallery block. Search matches every query word after case/accent normalization against card title/body/link labels/tags or image captions/alternative text/tags. One selected tag intersects with text. Each collection preserves authored order and independent state; count/reset/empty messages are translated properties. Hidden gallery items are removed from lightbox navigation. Without JavaScript all items remain visible. There is no site-wide index, server query, pagination or global taxonomy.

Video supports a local MP4/WebM upload, an existing HTTPS media URL, YouTube or Vimeo. Posters, WebVTT captions, transcript link and accessible title are authorable; provide captions/transcripts for spoken content. Uploads must already be browser-ready: the package does not transcode or claim codec compatibility from a MIME type. Default limits are 100 MiB video, 1 MiB captions and 10 MiB image. File contents/extensions are checked. The actual ceiling is the lowest package/PHP/web-server/Livewire temporary-upload limit. `site-builder:media-doctor` reports detectable limits; it cannot inspect a reverse proxy. Raise the host limits deliberately, then retest an actual upload. Existing image APIs and host media adapters keep their original behavior; implement TypedMediaResolver/TypedMediaPicker to opt a custom adapter into video/caption metadata.

Location offers address/directions and an optional Google Maps embed URL; paste the URL from a supported /maps/embed?pb= link, never iframe HTML. External video/map frames load only after the visitor activates them. Editor previews are inert. Re-publish component assets with the package installer after upgrading. All public interaction modules are local compiled files.
