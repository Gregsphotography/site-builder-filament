# Third-party materials

The package-owned PHP, Blade, JavaScript, CSS, schema and synthetic examples are released under MIT. Code-owned example SVGs are illustrative vectors, not customer photographs. No external font, uploaded media, consumer source, private release archive or vendor dependency tree is embedded in this package.

Composer resolves dependencies under their own notices/licences: Laravel/Illuminate, Filament, Livewire, Symfony HTML Sanitizer, Opis JSON Schema and PHP JSON Canonicalization retain their upstream licences. The esbuild contributor dependency is MIT. Refer to installed dependency licence files; this package licence does not replace them. The optional editor bundles the matching core preview protocol from its declared Composer dependency, covered by the matching core MIT licence.
